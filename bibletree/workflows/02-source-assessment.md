# 评估课程来源 1.0

继承 [CONTRACT](../CONTRACT.md)，按需加载 [FEATURE](../templates/FEATURE.md) 及书籍选定主模板。适用schema1，提示词提交由调用方固定。

## 输入

获准来源目录、明确发布revision、正文摘要/全文、连接授权与成果使用声明。

## 允许动作与提示词正文

仅分析、编纂草案或提出变更，不批准或部署。

按instance/course/version分组核对完整上下文、语言/页面稳定标识、修订hash与适用范围。区分可同步、可编纂、可独立发布三种资格；没有持续成果使用授权不能推断永久可展示。只读取获准范围，不导入草稿、私人笔记或讲师备注。发现同revision异hash、来源冲突或必要资源权限不明时列出阻塞。不把失联当撤回。

## 输出格式

来源评估表：sourceKey、revision、授权范围、可用目的、内容缺口、冲突、资源风险、建议绑定范围。 使用CONTRACT共同封套，证据使用稳定来源标识与连续引文，未知字段显式标记。

## 停止条件与验收

必要材料、权限或当前基线缺失时停止相关定稿并列出缺项。核对版本由来源明确指定，不猜最新；不创建或批准授权。 执行共同契约全部检查，未执行项如实列明。
