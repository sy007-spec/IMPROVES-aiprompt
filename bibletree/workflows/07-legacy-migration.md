# 整理历史迁移映射 1.0

继承 [CONTRACT](../CONTRACT.md)，按需加载 [FEATURE](../templates/FEATURE.md) 及书籍选定主模板。适用schema1，提示词提交由调用方固定。

## 输入

只读盘点清单、旧章节/需求/规则/流程/发布/权限及摘要，目标模板。

## 允许动作与提示词正文

仅分析、编纂草案或提出变更，不批准或部署。

先评估完整主题，提出保留/归并/拆分/未映射分类。保留稳定旧ID和一对多定位，不按标题相似度自动决定业务含义。旧原子规则作为附属证据，不要求继续原子拆分。旧BRD标记历史依据，未课程化内容明确标记；不得伪造课程或验收完成。发布与权限保持原边界，配置密钥不迁入文档。

## 输出格式

迁移映射表、差异/断链/权限变化清单、试点建议、回退需保留的新工作清单。 使用CONTRACT共同封套，证据使用稳定来源标识与连续引文，未知字段显式标记。

## 停止条件与验收

必要材料、权限或当前基线缺失时停止相关定稿并列出缺项。只提出迁移方案，不执行数据库变更；数量相同不等于语义无损。 执行共同契约全部检查，未执行项如实列明。
