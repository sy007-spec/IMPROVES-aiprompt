# 虚构示例：社区活动平台（WEAVE）

仅演示格式。使用 [WEAVE](../../templates/WEAVE.md) 与 [FEATURE](../../templates/FEATURE.md)，继承 [CONTRACT](../../CONTRACT.md)。

## 输入材料

虚构来源 s-demo/c-events/v1/r1 p1：“活动管理员发布报名活动；成员报名成功后，通知模块发送确认通知。” p2：“通知失败不撤销已成功的报名。”

## 组织输出

World：活动报名及确认通知，不含缴费。Entities：活动与报名由活动领域负责，通知投递由通知领域负责。Actions：报名成功触发通知请求。Views：成员查看本人报名的范围待确认，管理员权限限活动管理材料所述。Evidence：p1/p2。

跨域关系R1：活动域→通知域，输入报名成功事件，输出投递结果；失败不回退报名。重试次数、谁处理最终失败待确认。共享通知能力只定义一次。

## F-01 完整特性草稿

Frame：成员报名后得到确认通知，主归属活动领域。
Experience：管理员发布活动，成员报名成功，通知模块发送确认。
Authority：发布者为活动管理员；成员可报名；通知配置权限未提供。
Terms：报名成功与通知成功分离。
Unhappy paths：通知失败不撤销报名；失败重试待确认。
References：s-demo/c-events/v1/r1 p1/p2，连续依据“通知失败不撤销已成功的报名”。
Evaluation：通知故障时报名仍成功；不得把未说明的重试策略写成规则。
